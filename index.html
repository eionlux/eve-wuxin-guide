EVE无烬星河 · 新手入门指南

来源：自由百科，自由的百科全书（本页面由豆包整理，核验于2026年10月26日）

EVE无烬星河

类型大型多人在线（MMO）
新手推荐族加达里（C族）

《EVE无烬星河》（国际服名《EVE Echoes》）是由网易研发并发行的太空题材大型多人在线游戏（MMO），玩家以克隆飞行员的身份驾驶舰船，在高安、低安与00区域之间探索、战斗、制造与贸易。本条目为零基础新手提供从开局到中期的完整入门路线，目标是帮助玩家快速建立"先干什么、怎么打钱、怎么不浪费"的游玩框架。

本条目核心主线：过教程 → 练技能 → 开过渡船打钱 → 攒钱升巡洋/毒蜥。全程优先MK5白板便宜装备，保船不炸，技能集中不分散。
先做什么：做完全部职业任务（按F12，左下角共5个模块），这是真正的系统新手引导，教你熟悉际遇、异常、市场、制造等核心玩法。
最重要的生存提醒：EVE里你不会死，但船和装备会没。被反跳怪（跃迁干扰）锁住就跳不走，会被集火爆船——进任务先秒反跳怪，感觉危险直接跃迁跑，别硬扛。

新手成长路线总览

整个前期路线浓缩为4个阶段，每阶段对应主力船、当前目标和下一步动作。建议先看总览建立全局认知，再按分节逐步执行。

1
开局护卫期（约当天—3天）
主力：秃鹫级（加达里T2护卫，导弹船）
  • 核心任务：过完新手教程 + 全部5个职业任务模块
  • 技能：先学驱逐舰操作到3级，为换船做准备
  • 目标：熟悉跃迁、锁定、导弹风筝，别急着打高难
2
主力过渡期（约第1周）
主力：渡鸦级（加达里T4驱逐，新手最强过渡）
  • 配装：MK5小型导弹×3 + 护盾 + 加力，全部白板便宜装
  • 打钱：3—4级际遇、0级深渊（白板渡鸦可通刷）
  • 技能：驱逐工程学、驱逐防御升级、锁定系统、护盾技能点起来
  • 目标：攒第一桶金，为巡洋准备技能点
3
巡洋期（约第2—3周）
主力：狞獾级（C族导弹巡洋）→ 毒蜥级（新手毕业神船）
  • 狞獾：巡洋过渡，盾抗导弹，熟悉巡洋手感
  • 毒蜥：新手毕业船，盾厚+无人机输出，可刷5级际遇/深渊
  • 技能：巡洋操作、中型武器、护盾增强技能是核心
  • 目标：稳定刷钱，开始考虑长期发展方向
4
中期（约第1个月起）
主力：按发展路线选择战列/势力船
  • 战斗系：乌鸦级/狂怒者级等战列，配合势力核心
  • 建议：前期集中点1—2条技能线，别平均分散
  • 目标：技能成型，稳定刷高安/低安收益内容

第一件事：先做什么

很多新手做完开头教程就四处乱跑，其实职业任务才是系统引导你熟悉市场的真正入口。做职业任务能自然理解"际遇、异常、市场、制造"这些核心玩法，比看攻略更直观。

  1. 做完新手短教程（教你开船、开炮）。
  2. 按下 F12，找到左下角职业任务，做完商业、工业、探索、军事、高级军事共5个模块——这才是真正的新手引导。
  3. 开始练技能，先学驱逐舰操作到3级（只需不到3小时），为开过渡船做准备。

第一艘船与核心循环

游戏核心循环就一句话：接任务/进异常 → 打海盗 → 掉战利品和赏金 → 换成钱 → 买更好装备/船 → 打更高级内容。

新手期节奏：先拿开局赠送的护卫舰（C族可选秃鹫级），用它刷1—2级际遇，熟悉导弹风筝的拉距打法，不用急着投入。

阶段一：开局护卫期（约当天—3天）

主力船：秃鹫级（加达里T2护卫，导弹船）。开局教学送的护卫就够用，别买花哨的。

项目做法完成标准
任务过完开头教程 + 全部5个职业任务模块界面里"职业任务"全部点亮/完成
技能先学驱逐舰操作到3级，再补驱逐工程学、驱逐防御升级技能队列持续训练，不空转
打钱刷1—2级际遇，熟悉导弹风筝拉距能稳定完成，不爆船
保命上保险（选高级，T1船划算），记住爆船可用保险点恢复了解保险机制，学会查看爆船后修复指引

阶段二：主力过渡期（约第1周）

主力船：渡鸦级（加达里T4驱逐，新手最强过渡，通刷0级深渊）。这是你第一台真正的主力，教程四选一优先选它。

渡鸦级特点：3高槽、2中槽、3低槽；导弹远程风筝，必中不吃角速度，对新手最友好；特有加成导弹/鱼雷飞行速度+25%，导弹飞得快、不易空。

渡鸦级：加达里驱逐舰，导弹船，新手过渡神船。

渡鸦级推荐配装（全部MK5白板，便宜不怕炸）

槽位装备说明
高槽×3小型快速导弹发射器MK5（轻型导弹）导弹必中，风筝核心；别用鱼雷（射程极近，扛不住贴脸）
中槽小型掠能器MK5吸怪的电维持电容，让盾修持续运转
低槽×3小型护盾回充增量器MK5 + 小型加力燃烧器MK5 + 导弹制导计算机MK5盾修保命、加力拉开距离、制导计算机加射程输出
无人机轻型攻击无人机·大黄蜂MK5（一组）高速小船贴脸时放出补伤害，打完收回来
配装避坑：不要上T2/势力装（3型皮米C等），贵且耗电，渡鸦电容扛不住；全部MK5白板即可。改装件（插槽）前期可空着，稳定不炸船再加盾插。
游戏内舰船装配与属性界面：可查看每秒伤害、导弹/无人机槽位、电容等。

渡鸦风筝打法口诀

  1. 进际遇/异常，先锁定并优先击杀速度最快的小船（会贴脸的威胁最大）。
  2. 和目标保持约20km环绕，不要让怪近身。
  3. 掠能器：怪靠近到6km内再开吸电，离远没用。
  4. 护盾回充：不要常驻，盾掉到一半再开，回满立刻关，省电容。
  5. 加力：怪朝你冲、距离在缩短时开启，拉回18—22km后关掉省电。

阶段三：巡洋期（约第2—3周）

攒够钱和技能点后上巡洋。推荐顺序：狞獾级 → 毒蜥级。

船定位适用内容
狞獾级C族导弹巡洋，盾抗远程，从驱逐到毒蜥的跳板4级际遇、中型异常
毒蜥级混血巡洋，新手毕业神船，盾厚+中型无人机输出5级际遇、大部分深渊，长期刷钱主力

毒蜥不需要堆太多导弹技能，靠无人机输出，盾量厚容错高，是被公认的新手毕业船，可以一直用到准备开战列。

阶段四：中期方向（约第1个月起）

技能成型后选择长期发展方向：战斗系可走向乌鸦级/狂怒者级等战列，配合势力核心。建议前期集中点1—2条技能线，不要平均分散，否则什么都开不了。

保命与常见坑

爆船与保险

EVE里你不会死，但船和装备会没。要点：

  • 船首次爆掉后，主界面右下角会弹出修复窗口，用保险点以30%价格恢复。
  • 伊甸币和保险点兑换比例约1:7。
  • 建议给主力船买较高等级的保险；T1船保险划算（赔得多花得少），T2/势力船保险不划算。

完成确认与下一步

达到什么状态算过关：你能用渡鸦级稳定刷0级深渊和3—4级际遇不爆船，技能点已开始向巡洋倾斜，账户上有稳定收入——就可以攒钱上狞獾/毒蜥，进入中期。

进入下一阶段的信号：巡洋技能成型（巡洋操作+中型武器+护盾增强），已购入毒蜥级并配好MK5装，能通刷5级际遇。

之后可选择你的长期玩法：高安刷钱、加入军团参与团队活动、采矿制造，或向战列舰发展。
